## Source-grounded P0: native batch size amplification on the Swing EDT
`DesktopApp.extractDroppedPaths(Object)` accepted a provider-owned `List<?> files` and **allocated `new ArrayList<>(files.size())` before checking its capacity**. Each entry was then converted to Path on the Swing EDT, and `FileImportPolicy.plan` traversed all entries before reporting the 160-card limit. `chooserPaths` likewise allocated an array list based on the potentially unbounded native multi-selection array; direct `addFiles` also planned oversized user input without a fast count gate. A native provider returning very many paths could cause excessive memory allocations, block Explorer drag transactions, or freeze the UI, despite the app's strict 160-card target limit. The risk is demonstrated by exact source control flow and safe synthetic provider tests; do **not** claim a real OOM was deliberately executed.

## Minimal corrective change
`app/src/main/java/com/embasic/publicapp/DesktopApp.java`: one package-visible `requireBoundedImportBatch(int count, String source)` early fail-closed guard returns a clear no-partial-import 160-card error. Invoke in `extractDroppedPaths` **before** `new ArrayList<>(files.size())` and provider iteration, in `chooserPaths` before converting files, and in direct `addFiles` before calling `FileImportPolicy.plan`. At/below 160 input size, the original duplicate, extension, order, error and focused + tile behavior remains unchanged; GUI feedback for native drag still defers modal dialogs until Explorer releases its drag transaction. This is not an alteration of the PDF renderer.

`app/src/test/java/com/embasic/publicapp/DesktopImportBatchCapTest.java`: a single small synthetic headless class (3 JUnit cases): a 4096-item lazy Explorer list with accessor that throws if called demonstrates O(1) early refusal; a 161-item chooser array of nulls must be rejected by size before conversion; `Integer.MAX_VALUE` direct count and valid 160/two/single-file paths prove no regression or huge allocation. No external UYAP fixtures or physical Windows heap crash.
