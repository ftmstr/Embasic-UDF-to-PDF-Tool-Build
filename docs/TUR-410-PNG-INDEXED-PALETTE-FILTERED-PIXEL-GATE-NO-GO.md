## Independently reproduced P0
On local OpenJDK 21, an original indexed PNG with correct 8-bit IHDR, PLTE, zlib IDAT, per-chunk CRC and IEND is decoded by `javax.imageio.ImageIO.read` even when it references a pixel palette index for which no PLTE entry exists. With one declared color, source index 5 (and also 255) renders opaque black; with the two-color rights-clean regression, index 5 silently aliases the second green PLTE entry. Index 0 renders its declared color. No decoder exception is thrown. The Public synthetic UDF importer validates PNG framing, PNG CRCs, exact IDAT consumption, color type and palette byte length, but not the validity of each reconstructed pixel index. Thus successful PDF can invent visible image colors absent from source. This is a concrete synthetic PNG fidelity loss, NOT native UYAP validation.
